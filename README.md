# Daylight

A responsive, dependency-free task-list web app. Add, edit, complete, delete, and
search tasks; set due dates and priorities; or browse today's and completed tasks.

## Run

With Python 3 and Node.js available:

```sh
cd /root/task-list
npm start
```

Open http://localhost:3000. Run the model tests with `npm test`.

Tasks are stored locally in this browser, not in an account or on a server.
Clearing browser data removes them. Storage failures are displayed in the app.
No external services, build step, or package installation is needed.
